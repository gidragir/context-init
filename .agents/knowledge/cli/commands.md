# 🛠 Справочник команд: context-init (L2)

> Автоматически извлечено из конфигурации проекта (Rust (Cargo))

## Стандартные команды жизненного цикла

| Задача | Команда |
| :--- | :--- |
| **Сборка** | `rtk cargo build` |
| **Тестирование** | `rtk cargo test` |
| **Линтинг** | `rtk cargo clippy` |
| **Форматирование** | `rtk cargo fmt --check` |
| **Запуск** | `rtk cargo run` |

## Быстрый запуск
```bash
rtk cargo build
rtk cargo test
```
